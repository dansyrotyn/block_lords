# Block Lords

RPG-прототип: герой та обраний ворог по черзі ставлять магічні фігури на спільне поле 8×8. Очищення ліній завдає шкоди, перемоги відкривають шлях до вежі, золото дозволяє прокачувати героя.

## Запуск

```sh
npm run build
npm test
python3 -m http.server 8765 --bind 127.0.0.1
```

Відкрий http://127.0.0.1:8765/dist/blockbusters.html. Зібраний HTML можна відкрити напряму; для стабільного збереження краще користуватися одним локальним URL. Файл самодостатній, окрім необов’язкових Google Fonts. Збірка потребує Node.js 18+, без встановлення залежностей.

## Реалізовано

Ігровий інтерфейс повністю англійський. Карта, квести, прокачка та довгі результати підтримують свайп і перетягування прямо по вмісту; бічні скролбари приховані. Кнопки закриття мають SVG-хрестики й зону натискання 44×44 px.

- Довга мальована карта на пергаменті з одним плавним звивистим шляхом, підписами ворогів, позначками перемог і свайпом/перетягуванням. Play відкриває карту; унизу — окремі вікна прокачки й квестів.
- 12 ворогів на двох маршрутах: щуролюди, бандити, орки, демони; кожен третій — бос.
- Прокачка сили, HP і множника золота зі зростанням ціни.
- Монети на полі, нагороди за перемоги, повторні бої.
- Шість квестів і три досягнення з ручним отриманням нагород.
- Профіль у localStorage; при недоступному сховищі — лише поточна сесія.
- Меню за наданим UI, кам’яна арена, магічні блоки, портрети героя, щура, бандита, орка й демона.

Це PvE проти ботів. Баланс початковий для плейтесту. Правила та наступні кроки: [геймдизайн](docs/game-design.md).

## Код

| Файл | Призначення |
| --- | --- |
| src/engine.js | Поле, фігури, шкода, ходи, AI |
| src/campaign.js | Економіка, вороги, квести, профіль |
| src/rpg-ui.js | Карта, прокачка, нагороди та квести |
| src/map.css | Мальована карта, нижня навігація та окремі вікна |
| src/game.html | Екрани, адаптивність, перетягування, анімації, звук |
| build.js | Збірка dist/blockbusters.html |
| tools/test.js, tools/campaign_test.js | 28 перевірок рушія та прогресії |

Ключ профілю: block-lords.campaign.v1. localhost і 127.0.0.1 мають окремий прогрес. Вихід або перезавантаження незавершеного бою скасовує його нагороди.
