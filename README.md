# Blockbusters

PvP-дуель у стилі Match Masters, де кор-механіка — Block Blast. Двоє гравців ставлять кам'яні фігури на спільне поле 8×8. Кожна закрита лінія б'є по HP суперника. Суперник — бот, який для гравця виглядає як живий: ім'я, прапор, аватарка, «палець», що тягне фігури.

Гра — це чистий HTML, CSS і JavaScript без фреймворків і залежностей.

## Швидкий старт

- **Просто пограти:** відкрий `dist/blockbusters.html` у браузері. Найкраще на телефоні або в режимі телефона в DevTools (Chrome: F12 → Toggle device toolbar).
- **Викласти в інтернет:** `dist/blockbusters.html` — це один самодостатній файл. Його можна покласти на будь-який статичний хостинг (GitHub Pages, Netlify, itch.io як HTML5-гру).
- **Зібрати після змін:** потрібен Node.js 18+, нічого встановлювати не треба.

```
node build.js          # або: npm run build  → dist/blockbusters.html
npm test               # 13 тестів рушія
npm run sim            # бот проти бота: баланс рівнів, перевага першого ходу
npm run sim:ko         # як часто і в якому раунді стається нокаут
```

## Структура

```
blockbusters/
├── src/
│   ├── engine.js        логіка гри без UI: поле, фігури, очки, HP, бомби, x2, бот
│   └── game.html        уся гра: екрани, стилі, анімації, звук, перетягування
├── assets/
│   ├── art/             фон головного екрана, поле, камінь, фон матчу
│   ├── avatars/         37 аватарок суперників
│   ├── player.jpg       аватарка гравця (сірий силует)
│   └── sfx/             звуки (ім'я файлу = ім'я звуку в коді)
├── tools/               тести й симуляції балансу
├── build.js             вшиває рушій, арт, аватарки й звуки в один HTML
└── dist/blockbusters.html   готова зібрана гра
```

`src/game.html` — це шаблон. У ньому є мітки (`/*ENGINE*/`, `/*AVATARS*/`, `/*SFX*/`, `__HOME__`, `__BOARD__` тощо), які `build.js` замінює на код і файли. Тому редагувати треба `src/`, а потім запускати збірку. Правити `dist/` напряму не варто, бо його перезапише наступна збірка.

## Що де крутити

### Баланс — `src/engine.js`, об'єкт `CONFIG`

| Параметр | Зараз | Що робить |
| --- | --- | --- |
| `hp` | 100 | здоров'я кожного гравця |
| `rounds` | 10 | ліміт раундів, якщо ніхто не впав у нокаут |
| `baseActions` | 3 | скільки фігур ставиш за хід |
| `maxBonusActions` | 2 | скільки бонусних дій можна отримати за комбо за один хід |
| `turnSeconds` | 20 | таймер ходу |
| `lineBase` | 10 | очки: 10 · n(n+1)/2 за n ліній однією дією |
| `bombPerBlock` | 5 | шкода за кожен блок, знищений бомбою |
| `maxMultiplier` | 4 | стеля для x2 (два множники в одній дії = x4) |
| `specialChance` | 0.12 | шанс, що в фігурі буде бомба або x2 |
| `startBlocks` | 8 | каменів на полі на старті |
| `firstFinalBonus` | 0 | +дії першому гравцеві в останньому раунді (1 вирівнює перевагу другого ходу) |

Набір фігур і їхні ваги задає масив `SHAPES` на початку `engine.js`.

### Бот

- Рівні `easy`, `medium`, `hard` описані у функції `chooseMove` в `engine.js`.
- Складність прихована й адаптивна. Масив `MIX` у `game.html` має 5 кроків. Перемога гравця піднімає крок, поразка або вихід з матчу знижують. Крок зберігається в `localStorage`.
- «Людська» поведінка (пауза на роздуми, вагання над іншою клітинкою, рух пальця) зібрана у функції `botAct` у `game.html`.

### Суперники

- Імена за країнами — об'єкт `COUNTRIES` у `game.html` (28 країн, по 6 імен). Прапори намальовані в SVG у функції `flagInner`.
- Приблизно 30% суперників отримують ім'я на кшталт `Guest54914` (функція `makeOpponent`).
- Прапор гравця визначається з мови браузера, за замовчуванням 🇺🇦 (функція `playerCountry`).
- Щоб додати аватарку, поклади `.jpg` у `assets/avatars/` (бажано 112×112) і перезбери гру.

### Звуки

Ім'я файлу в `assets/sfx/` — це ім'я звуку в коді. Гучність кожного задається в `SFX_VOL` у `game.html`. Щоб замінити звук, поклади файл з тим самим ім'ям (`.mp3` або `.wav`) і перезбери гру.

| Звук | Коли грає | Файл-джерело |
| --- | --- | --- |
| `play` | PLAY, PLAY AGAIN | SFX_UI_Click_Buy_1 |
| `tap` | кнопка звуку, клацання барабана аватарок | SFX_UI_Click_Liquid_Generic_1 |
| `open` | відкрити меню виходу з матчу | SFX_UI_Click_Crispy_Open_1 |
| `back` | Cancel, Home, Stay, Leave | SFX_UI_Click_Crispy_Close_1 |
| `land` | барабан зупинився на супернику | SFX_UI_Click_Select_1 |
| `pick` | взяв фігуру (і бот теж) | SFX_UI_Click_Liquid_Open_1 |
| `invalid` | відпустив фігуру не туди | SFX_UI_Click_Liquid_Close_1 |
| `turnend` | твій хід закінчився | SFX_UI_Click_Liquid_Close_2 |
| `place1`, `place2` | поставив фігуру (навмання один з двох) | SFX_Object_Place_Generic_1/2 |
| `loop_melody` | музика під час пошуку суперника | SFX_Countdown_Melodic_Loop_1 |
| `loop_mech` | таймер: з 10 до 5 секунд | SFX_Countdown_Mechanic_Loop_1 |
| `cdstart` + `loop_fast` | таймер: останні 5 секунд | SFX_Countdown_Start_1 + SFX_Countdown_Fast_Loop_1 |
| `timeup` | час вийшов | SFX_Countdown_End_Fail_1 |
| `found` | суперника знайдено | uisfx: arcade/connect |
| `yourturn` / `oppturn` | банер YOUR TURN / OPPONENT'S TURN | uisfx: rubber/notification, organic/info |
| `clear` | зібрана лінія | uisfx: organic/complete |
| `hit` | удар по HP | uisfx: organic/snap |
| `combo` | комбо +1 дія | uisfx: arcade/streak |
| `x2` | спрацював множник | uisfx: glass/bonus |
| `bomb` | вибух бомби | uisfx: cinematic/blocked |
| `ko` | нокаут | uisfx: cinematic/stop |
| `win` / `lose` / `draw` | екран результату | uisfx: arcade/achievement, soft/error, soft/complete |

Звук стартує після першого дотику до екрана, так вимагають браузери. На iPhone також треба вимкнути беззвучний режим.

## Як влаштований `game.html`

Скрипт поділено на розділи з коментарями `// ---------- … ----------`:

- **sound** — Web Audio: розблокування після дотику, `sfx()`, цикли `loopSfx()`, музика пошуку, звуковий відлік таймера.
- **scene** — фони головного екрана й матчу, розміщення кнопки PLAY над фоном.
- **board** — розмір поля (`layout`) і малювання клітинок (`renderBoard`).
- **HP**, **timer ring** — смужки здоров'я, прев'ю шкоди, таймер-медальйон.
- **effects** — банери, розліт каменів у HP (`flyBlocks`), іскри, вибухи.
- **turn flow** — `step()`: хто ходить, банери, застрягання, тайм-аут.
- **the opponent's "finger"** — `botAct()`: анімація ходу бота.
- **player's drag** — перетягування фігур (слухає `window`, щоб на телефоні дотик не губився).
- **matchmaking** — `startSearch()`: барабан аватарок і вибір суперника.

`window.__bb` — службовий хук для автотестів у браузері. Перед релізом його можна видалити.

## Для переносу на Unity або Godot

`src/engine.js` не залежить від браузера. Це чиста логіка з детермінованим генератором випадковості (`S.seed`), тож одна й та сама послідовність ходів завжди дає той самий результат. Її можна переписати на C# або GDScript майже рядок у рядок, а тести з `tools/test.js` перенести як еталон.

## Джерела й ліцензії

- **Арт** (фон, поле, камінь, логотип) вирізано з макетів автора гри.
- **Аватарки** — з набору автора гри. Фото реальних людей і персонажів брендів у гру не потрапили.
- **Звуки SFX_*** — надані автором гри.
- **Решта звуків** — бібліотека [uisfx](https://www.npmjs.com/package/uisfx), ліцензія CC0 (див. `assets/sfx/LICENSE-uisfx.txt`).
- **Шрифти** Lilita One і Fredoka вантажаться з Google Fonts (SIL Open Font License). Без інтернету браузер підставить запасний шрифт.
